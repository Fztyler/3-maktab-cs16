# de_3_maktab — школа для Counter-Strike 1.6

Карта режима закладки бомбы по эскизу школы в Blender. Большой и малый корпуса двухэтажные; спортзалы — высокие одноэтажные. На территории есть ограждённое футбольное поле, южный забор и стены с остальных сторон.

## Скачать и установить

1. Скачайте [de_3_maktab_install.zip](de_3_maktab_install.zip).
2. Распакуйте его в папку `Counter-Strike-1.6`, сохранив вложенную папку `cstrike`.
3. В CS 1.6 выберите карту `de_3_maktab` при создании игры или введите в консоли `map de_3_maktab`.

В архиве находятся только необходимые для игры файлы: `cstrike/maps/de_3_maktab.bsp` и `cstrike/3_maktab.wad`. Их также можно скачать из корня репозитория по отдельности. Для игры нужны стандартные текстуры CS 1.6.

## Правила и ориентиры

- Террористы появляются у футбольного поля; спецназ — у южных ворот.
- Плент A — библиотека на втором этаже малого корпуса; плент B — западная сторона большого корпуса. Оба места отмечены красными A/B.
- У обеих команд есть зоны покупки у точек появления.
- Для установки с AMX Mod X файлы из `config/` можно положить в `cstrike/addons/amxmodx/configs/maps/`. Они задают раунд 5 минут, стартовые $800 и отключают тренировочные плагины на этой карте. В обычной CS 1.6 действуют правила сервера.

## Исходники

`3m.blend` — исходный эскиз; `de_3_maktab.map` — редактируемая карта GoldSrc; `build_map.py` и `make_wad.py` — скрипты сборки; `verify_map.py` проверяет игровые сущности и столкновения. Сборочные скрипты используют пути автора к Blender, CS 1.6 и sdHLT — при повторной сборке их нужно изменить.

Это первая играбельная версия. Компилятор не сообщил об ошибках, а геометрия появления игроков и плентов проверена. Полный тест раунда с несколькими игроками ещё нужен для поиска оставшихся неудобных мест.
