ГОТОВЫЙ ИСХОДНИК ДЛЯ РУЧНОГО РЕДАКТИРОВАНИЯ

Открывай de_3_maktab.map через File > Open в редакторе GoldSrc. Это исходная геометрия, а не декомпиляция BSP. Формат Valve 220. Версия соответствует последней установленной карте с западным фасадом, туалетами восточнее и исправленными дверями для ботов.

Настрой игровую конфигурацию Half-Life / Counter-Strike:
- Каталог игры: N:\Counter-Strike 1.6
- Мод: cstrike
- Game Data / FGD: maktab.fgd из этой папки. Он содержит все использованные классы; дополнительных FGD не требуется.
- Текстуры: 3_maktab.wad и sdhlt.wad из этой папки; cstrike.wad, cs_office.wad, cs_dust.wad из установленной cstrike; halflife.wad из valve.
- Модели находятся в cstrike/models/maktab/ и установлены в игре. Для отображения студийных моделей укажи редактору каталог игры и мод.

1. Сохрани копию de_3_maktab.map и редактируй карту.
2. Закрой CS. Запусти compile_and_install.cmd.
3. После успешной сборки запускай de_3_maktab. При изменении геометрии заново построй маршруты ботов: bot_nav_analyze.

Сценарий сборки проверен на синтаксис. Формат MAP проверен компиляторами CSG и BSP, сохранение UV и коллизии проверено отдельно. Сценарий не запускает Blender и не перезаписывает твой MAP. Перед установкой он сохраняет резервные копии в backups/.
Для ускорения сборки используется быстрый VIS. Полный: запуск compile_and_install.ps1 с параметром -FullVis; он может работать долго.

В редакторе можно менять стены, двери, лестницы, окна, парты, спауны и зоны плентов. Деревья и мелкие предметы объединены в MDL-группы: одну группу можно перемещать, отдельный предмет внутри неё требует изменения модели. У стволов отдельные CLIP-блоки, их нужно передвигать вместе с деревьями.
X — восток, Y — север, Z — вверх. Полы большого корпуса: Z=8 и Z=192. Малого: Z=8 и Z=136.

Нужен именно редактор GoldSrc. Не открывай эту карту как карту Source / CS:GO / CS2. Если импорт выдаёт ошибку, проверь игровую конфигурацию и формат Valve 220:
https://jack.hlfx.ru/ru/articles/1/faq.html

После ручных правок собирай карту этой кнопкой, а не build_map.py: генератор относится к отдельному автоматически создаваемому исходнику.

ОБНОВЛЕНИЕ: НЕЗАВИСИМЫЕ СТЕКЛО И РАМА, ТУАЛЕТЫ НА ВОСТОКЕ
Стекло: material=0, health=20; деревянная рама: material=1, health=35. У каждой рамы target указывает на targetname её стекла. Стекло можно разбить отдельно, а разрушение рамы разбивает и оставшееся стекло.
При копировании окон задавай каждой паре новые уникальные имена и поправляй связь target. После компиляции обязательно выполняется share_window_models.py: он повторно использует одинаковые модели, сохраняя раздельный урон у всех окон. Скрипт сборки уже вызывает его. Нужен Python 3, который установлен в текущем окружении. Не пропускай этот шаг — иначе возможен лимит моделей GoldSrc.
Плагин maktab_penetration.amxx нужен на сервере для корректного отображения большого числа отдельных частей окон и групп моделей. В текущей игре он установлен вместе с зависимостями. Для другого сервера установи комплект поддержки карты. Клиентам AMXX не требуется.
Туалеты стоят у крайней восточной стены с проходом около метра; плент B перенесён к ним.

Смена команды: M, обычное правило одной смены за раунд. mp_limitteams=0, люди могут выбрать T или CT; настройки включены в эту копию.

ОБНОВЛЕНИЕ ПОТОЛКОВ И ДВЕРЕЙ
Потолки на каждом этаже выше на 16 единиц GoldSrc (около 40 см). Лестницы, верхние площадки, мебель и точки появления согласованы с новыми полами. У всех 67 дверей сплошные косяки и перемычки, полотно подогнано по проёму, текстура отображается целиком. Удалены все навесные таблички/плакаты, кроме одной таблички на сплошной части козырька большого корпуса. Старые ручные копии не перезаписывались.
